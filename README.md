# BRAIN-HEMORRAGHE-DECTETION
🧠 Brain Hemorrhage Detection using Machine Learning and Deep Learning
📌 Project Overview

Brain hemorrhage is a critical medical condition that requires rapid and accurate diagnosis to reduce mortality and long-term complications. This project focuses on the automatic detection of brain hemorrhage from medical imaging data using both Machine Learning (ML) and Deep Learning (DL) techniques.

The goal of this project is to compare traditional ML models with advanced DL models and evaluate their effectiveness in detecting brain hemorrhage accurately.

🎯 Objectives

To detect the presence of brain hemorrhage from medical images

To implement and compare Machine Learning and Deep Learning models

To analyze model performance using standard evaluation metrics

To improve early diagnosis support for medical professionals

🗂️ Dataset

Medical imaging data (CT scan images of the brain)

Dataset includes hemorrhage-positive and hemorrhage-negative samples

Images were preprocessed using normalization, resizing, and augmentation techniques
